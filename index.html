FortiAuthenticator Guest Wi-Fi Facebook Login

This site provides information about a limited-purpose Facebook Login integration used to authenticate users to a guest wireless or captive-portal network through FortiAuthenticator.

How it works

  1. A user connects to a participating guest network.
  2. The network redirects the user to a FortiAuthenticator captive portal.
  3. The user chooses Login with Facebook.
  4. Facebook authenticates the user and, where applicable, asks for consent to the limited information requested by the application.
  5. Facebook redirects the browser back to FortiAuthenticator.
  6. FortiAuthenticator uses the returned authentication information to create or identify a social guest account and establish an authenticated guest session.
  7. The network may then provide the guest access permitted by its policy.

Information requested

The application is designed to request only the minimum information needed for authentication. Depending on the permissions enabled and information made available by Facebook, this may include an app-scoped Facebook user identifier, name/basic public profile information, and an email address where the email permission is enabled and returned.

The application is not designed to access Facebook posts, private messages, friend lists, photos, advertising accounts, Pages, payment information, or other Facebook content unrelated to authentication.

Purpose

Facebook-derived information is used only to authenticate a guest-network user, associate the authentication with a FortiAuthenticator social-user record or guest session, provide or administer permitted network access, enforce authentication and security policies, and maintain necessary security or operational records.

Information obtained through Facebook Login is not sold and is not used for targeted advertising or unrelated marketing.
